# Promo « 100K → 500K 💎 en 90 jours » — kit marketing

Vidéo : `Promo500k` (9:16, 48 s, son inclus) → `npm run audio:500k && npm run render:500k`

## Structure de la vidéo (et le levier marketing de chaque bloc)

| Temps | Bloc | Levier | Ce qu'on voit |
|---|---|---|---|
| 0–4 s | **Hook** | Interruption + identification immédiate | Compteur 💎 bloqué à 100 000, tampon « PLAFOND » |
| 4–9 s | **Agitation** | Douleur vécue | « Tu lives tous les jours. Mêmes viewers. Mêmes donateurs. Même plafond. » + courbe plate |
| 9–16 s | **Diagnostic** | Déculpabiliser + autorité (« on sait pourquoi ») | 3 blocages : events, donateurs, matchs |
| 16–22 s | **Révélation** | Promesse chiffrée + transformation | Compteur 100K → 500K, courbe qui décolle, « EN 90 JOURS » |
| 22–32 s | **Plan 90 jours** | Mécanisme unique (crédibilité de la promesse) | 3 phases + outils LiveMatch / LiveShow / LiveAngel / LiveSuccess + manager dédié |
| 32–37 s | **Preuve** | Preuve sociale + autorité | N°1 agréée 2023, +10 000 créateurs, +8 prix |
| 37–42 s | **Pour qui** | Qualification (filtre les petits comptes, valorise le prospect) | 4 critères |
| 42–48 s | **CTA** | Action à friction minimale + mesurable | Commenter « 500K » / livesuccess.app |

## Textes publicitaires (TikTok Ads / Meta)

**Texte principal A (douleur)** : Tu fais déjà 100K 💎/mois mais tu stagnes ? 3 blocages t'empêchent de passer le cap. Notre plan 90 jours les règle un par un.
**Texte principal B (preuve)** : 1ère agence TikTok LIVE agréée en France. +10 000 créateurs accompagnés. Objectif : t'emmener de 100K à 500K 💎/mois en 90 jours.
**Texte principal C (qualification)** : Ce programme n'est PAS pour les débutants. Tu fais déjà ~100K 💎/mois et tu lives régulièrement ? On a un plan pour toi.
**Bouton** : « En savoir plus » → livesuccess.app

## Plan de test conseillé

1. J1–J3 : organique sur le compte LiveUp + 3 créateurs ambassadeurs (même vidéo, leur compte = plus de confiance).
2. J3–J7 : TikTok Ads, 3 accroches × 10 €/jour, ciblage FR 18-34 intérêts « LIVE / gaming / créateurs ».
3. KPI à suivre : rétention à 3 s (> 40 %), vue complète (> 15 %), commentaires « 500K », coût par prospect qualifié.
4. On coupe les accroches sous 30 % de rétention à 3 s et on double le budget sur la meilleure.

## ⚠️ Conformité

- « 500K en 90 jours » est un **objectif**, pas une garantie : la mention « Objectif indicatif · les résultats dépendent de l'implication de chaque créateur · 18+ » est affichée à la fin. À garder pour TikTok Ads (politique sur les promesses de revenus).
- Les paliers 150K / 300K / 500K du plan sont des objectifs indicatifs à valider en interne.
- Le téléphone est une maquette stylisée (pas de logo TikTok) : pas de souci de marque.
